# ELLE - External Learning Loop Engine

A production-ready, testable Python library under a standard src layout
with clean domain models, engine orchestration, and integration
interfaces for SHARON/ERIE exchanges.

Core concepts:
- event ingestion
- work parcel lifecycle
- GRAY gossip state management
- maturity pressure evaluation
- rule promotion
- ancestry tracking
- SHARON/ERIE exchange interface

Run the test suite from the project root:

    python -m pytest
